# 스마트 조선소 일반 작업자 앱

현장 일반 작업자가 모바일에서 오늘 작업을 확인하고, TBM 안내를 청취·확인하고, 개인 보호구 체크와 위험 신고를 수행하는 Android 앱입니다.

## 작업자 기능

- Spring Boot API 기반 작업자 로그인·로그아웃과 세션 유지
- 오늘 작업허가, 작업 시간·위치·승인 조건 확인
- TBM 안내 조회, 현재 앱 언어로 TTS 재생, 확인 처리
- 로그인부터 작업·TBM·개인 체크·위험 신고·내 정보까지 12개 언어 UI 적용
- 안전화·보호장갑·작업복 직접 체크
- 원본 사진 촬영 후 YOLO 안전 장비 착용 판정 및 개인 체크 제출
- 위험 유형, 사진, 상세 설명을 포함한 위험 신고와 내 신고 내역 조회
- 백엔드 없이 전체 작업 흐름을 확인할 수 있는 명시적 데모 모드

반장용 TBM 작성, 참석 인원 관리, 교육 증빙 사진 제출 기능은 포함하지 않습니다.

로그인 화면의 `서버 없이 데모 시작`을 누르면 서버와 DB 없이 예시 작업·TBM·개인 체크·위험 신고 흐름을 확인할 수 있습니다. 데모 보호구 판정에는 `실제 판정 아님`이 표시됩니다.

## 실행

Android Emulator에서는 PC에서 Docker로 실행한 백엔드 `http://10.0.2.2:8180`에 연결합니다.

```powershell
.\gradlew.bat :app:assembleDebug
```

생성 APK: `app/build/outputs/apk/debug/app-debug.apk`

실제 Android 기기에서 로컬 백엔드를 사용할 때는 에뮬레이터 전용 주소인 `10.0.2.2` 대신 개발 PC의 LAN 주소를 지정합니다.

개인 보호구 판정은 백엔드가 별도의 YOLO 추론 서비스에 연결합니다. 모델 가중치와 실행 방법은 `../빅프/ai/ppe_detector/api/README.md`를 참고하세요. 모델이 없거나 서비스가 중단된 경우 앱은 판정을 통과시킨 것처럼 처리하지 않고 오류를 표시합니다.
